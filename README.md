# Programación orientada a PLN — Materiales

Material docente de la asignatura *Programación orientada a PLN* (Universidad Pontificia Comillas), organizado por tema.

🔗 **Acceso:** https://blancahpardo.github.io/pln/

## Estructura

- `index.html` — portada de la asignatura, con acceso a cada tema.
- `t0a/` — Tema 0 · Recordatorio de Python
- `t0b/` — Tema 0 · Regex
- `t1/` … `t8/` — Tema 1 a Tema 8

Cada tema está protegido con una contraseña (facilitada en clase) y da acceso, según se vaya habilitando, a: manual teórico en PDF, cuaderno principal y cuaderno evaluable para descargar, documento de prácticas (solo lectura) y un cuestionario de práctica con puntuación sobre 10.
